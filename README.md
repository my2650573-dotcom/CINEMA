# CINEMA

An Android series discovery catalog with a premium black-and-gold interface.

## Features
- Arabic RTL interface
- Series catalog, search and genre filters
- Favorites saved locally on the device
- Series details and external links to official streaming platforms
- Android WebView shell

## Build
The project is configured for Android Gradle Plugin 8.2.2, Java 17, compile SDK 34.
GitHub Actions builds a debug APK on every push to `main`.

> This starter catalog is a demo. Availability and licensing vary by region. The app links to official platform homepages and does not host or redistribute video.
